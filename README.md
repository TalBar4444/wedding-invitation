# Wedding invitation

Design studio for Tal & Shaked’s invitation. **RSVP-Ease only uses the exported PNGs** — it does not run this compositor.

## Develop

```bash
npm install
npm run dev
```

Toggle landscape / portrait, then **Download PNG**.

## Hand off to RSVP-Ease

Copy the downloads into the RSVP app as:

- `RSVP-Ease/public/invitation/invitation-landscape.png`
- `RSVP-Ease/public/invitation/invitation-portrait.png`
